# Island Asylum concept preview

Static HTML concept demo, preserved from the supplied mockup. No install or build is required. Open `index.html` locally.

## GitHub Pages

The `pages.yml` workflow publishes `index.html` and `robots.txt` on pushes to `main`. In repository Settings → Pages, select **GitHub Actions** as the source if it is not already enabled. The intended URL is https://jay-rtl.github.io/sample2/; deployment must succeed before this URL is available.

## Review before an official launch

- This is a concept preview with an explicit notice and search indexing disabled. A sitemap is intentionally omitted.
- Confirm permission to publish the brand, images, book descriptions, quoted text, and business claims. Images are loaded from islandasylum.com and depend on that server.
- Replace bookstore homepage links with verified product URLs before labeling them as purchase links.
- Replace design commentary and confirm forthcoming-title information before an official launch.
- All contact actions open the external business website. This demo has no forms, backend, analytics, cookies, or submission storage.
- Browser rendering, keyboard behavior, external links, image availability, performance, and the live deployment require verification. Source checks are not a full accessibility or security audit.
